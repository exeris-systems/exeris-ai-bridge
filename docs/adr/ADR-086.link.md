# ADR-086 — [Subject] (link stub)

**Authoritative copy:** [`exeris-docs/docs/adr/ADR-086.md`](https://github.com/exeris-systems/exeris-docs/blob/main/docs/adr/ADR-086.md)

ADR-086 is a **cross-repo** decision owned by `exeris-docs`. It defines the subject that this repository consumes.

## Why this stub exists

The bridge is bound to ADR-086 §A.3 as a context adapter under ADR-025; it is never a host of capture, a dataset, or an oracle.

## When to consult ADR-086

- Implementing or modifying tool handlers that interact with the subject of ADR-086.
- Verifying the contract of the context adapter against the target implementation.

## Consumer-side obligations from ADR-086

- The adapter MUST adhere to the interaction patterns defined in ADR-086 §A.3.
- Implementers MUST ensure that the bridge remains a read-only introspection surface.
