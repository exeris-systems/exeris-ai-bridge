# ADR-086 — Context Adapter Interface — Bridge-side Adapter for ADR-025 (link stub)

**Authoritative copy:** [`exeris-ai-execution/docs/adr/ADR-086.link.md`](https://github.com/exeris-systems/exeris-ai-execution/blob/main/docs/adr/ADR-086.link.md)

ADR-086 is a **cross-repo** decision owned by `exeris-ai-execution`. It defines the interface and lifecycle requirements for context adapters used by `exeris-ai-bridge`.

## Why this stub exists

ADR-086 §A.3 binds the bridge to a context adapter under ADR-025, and not to a host of capture, a dataset, or an oracle.

## When to consult ADR-086

- Implementing or modifying any tool handler under the context adapter surface.
- Building or updating the adapter integration in `src/transport/`.
- Any change to the interface assumed by bridge-side testing.

## Consumer-side obligations from ADR-086

- The bridge MUST treat the adapter as a strictly defined service.
- The adapter MUST not attempt to act as a data provider or an execution engine itself.
- No client-side local state should be relied upon for lifecycle management.
