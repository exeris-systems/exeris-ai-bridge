# ADR-086 — Context Adapter Binding (link stub)

**Authoritative copy:** `exeris-ai-execution/docs/adr/ADR-086.link.md`

ADR-086 is a **cross-repo** decision. It defines the bridge's binding to a specialized context adapter.

## Why this stub exists

This stub exists because ADR-086 §A.3 binds the bridge to a context adapter under ADR-025, never a host of capture, a dataset or an oracle.

## When to consult ADR-086

- Implementing or modifying bridge-side logic for context/execution runtime.
- Any change to the semantic contract of execution-related tools.
